# Rock Paper Scissors 🎮

A simple and interactive **Rock Paper Scissors** game built with **HTML, CSS, and JavaScript**.

The project allows the user to choose Rock, Paper, or Scissors while the computer randomly selects its move. The game automatically determines the winner and keeps track of the score.

## 📌 Features

* 🎮 Interactive Rock Paper Scissors gameplay
* 🤖 Random computer choice
* 🏆 Automatic winner detection
* 📊 User and computer score tracking
* 🔄 Reset/New Game functionality
* ⚡ Fast and lightweight
* 📱 Responsive interface
* 🎨 Simple and clean UI

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling and responsive layout
* **JavaScript (ES6+)** — Game logic and interactions

## 🎯 How the Game Works

The game follows the classic Rock Paper Scissors rules:

| Player      | Beats       |
| ----------- | ----------- |
| 🪨 Rock     | ✂️ Scissors |
| 📄 Paper    | 🪨 Rock     |
| ✂️ Scissors | 📄 Paper    |

If both the player and computer choose the same option, the game is a draw.

## 🧠 JavaScript Logic

The game uses JavaScript to:

1. Detect the player's selected choice.
2. Generate a random computer choice.
3. Compare the two choices.
4. Determine whether the player wins, loses, or draws.
5. Update the scoreboard.
6. Display the game result.
7. Reset the game when requested.
